# NearSend 1.3.0

- 新增主题切换，支持跟随系统、浅色和深色模式，并同步状态栏与导航栏样式。
- 新增 NearSend、LocalSend、OLED 和自定义配色，支持预设主题色、颜色滑块及十六进制色值输入，并保存外观偏好。
- 首页、侧边栏与设置页 Logo 跟随当前主题色，统一静态图标和加载动画的配色。
- 修复 PC 中文输入后最小化窗口时，输入法原生回调提前释放导致的崩溃。
- 修复隐藏输入法时重复调用隐藏接口、递归触发回调的问题。
- 进一步优化滚动帧调度和矩形绘制，改善设置等长列表页面的滑动与渲染表现。
- 更新 GPUI/gpui-ohos 图形框架，统一接入 OpenHarmony Ability 1.0.0-beta.3 系统能力组件。
- 完善应用主动重启时的恢复支持。
