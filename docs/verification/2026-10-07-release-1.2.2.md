## 构建及签名

- arm64 原生 `ohrs build --release -- --locked` 通过；本次重新编译 NearSend 1.2.2，首页版本显示已验证。
- Hvigor Release `assembleHap` / `assembleApp` 均通过，包内 `debug=false`。
- 正式 APP/HAP 使用已有 `publishrelease` 签名，签名验证工具均通过，profile 类型为 `release`。
- 模拟器使用同一份代码构建的 default 签名 Release HAP；其 profile 类型为 `debug`，编译模式仍为 Release，包内 `debug=false`。
- 三个产物的 ArkTS `modules.abc` 相同；22 个有文件内容的 native ELF allocated section 相同，并与本次新编译原生库一致。打包裁剪符号导致整个 `.so` hash 不同，不影响上述比较。
- 未包含 `PAD_FOLDER_PROBE`、`SCROLL_TRACE`、`AUDIT_QA`、`FFRT_APP_QA`、`GESTURE_AUDIT` 或旧 `pick-directory` 标记。
- 签名在隔离工程中切换，原项目私有 `build-profile.json5` 的 hash 保持不变。
